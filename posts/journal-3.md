This week, my main goal was to get a state machine for the boss so that it can wander around on its own, and attack in cycles. I successfully implemented that this week. I followed a youtube tutorial which I will link below. It was somehwat difficult still to implement even with a step by step tutorial because his code was set up different than mine. For starters, he had an animationPlayer node with all of his animations set up with key frames for his sprites. I have used an animatedSprite2D with sprite sheets to make my animations. This made the code to play animations somehwat different. His enemy code was also set up different than mine so I needed to keep back tracking and change something in my own code to make this version work, but I'm happy with how it turned out. I also implemented a hitbox for the player attack that only detects collision when the attack animation is playing. This is to work towards our goal of having something playable this week. Also I added borders to the dungeon room. A video of the current version of the main scene is linked below. I have also linked below my github commit with all of this work. This week, I anticipated the state machine implementation would take a while, and then it did in fact take a while, so I wasn't surprised by it. I anticipated this because I knew the tutorial wouldn't fit my code exactly and I would have to refactor parts to make it work. I encountered a somewhat large error while working this weekend. Sean and I were both working on different scenes at the same time and he finished his work and committed it before I was done with mine. I decided to go ahead and meerge his work with what I had so far and doing this ended up corrupting one of our scene files. We were all very confused because neither of us were even working on the scene file that ended up eing corrupted. To solve this, I had to open the scene file in a text editor and fix one of the references inside the file to what it was before. Surprisingly it worked and we have not had any problems with it since, but it was scary at first and took time away from the work I was in the middle of doing, which was frustrating. I feel like our communication as a team has been good. We have a groupchat on discord where we always message whenever we make a new commit to the repo, we ask each other questions, and I especially try to keep everyone on schedule. I will send reminders of work or our standups to everyone to make sure we complete our tasks. It could always be better, but so far it has worked and we have had minimal problems I would say (exepct for the one I just talked about).
